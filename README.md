# Swiggy Food Data Analysis

## Project Overview
This project explores Swiggy food data using Microsoft Excel to understand food pricing, restaurant ratings, food categories, and geographical patterns.

## Tools Used
- Microsoft Excel
- Data Analysis
- Data Visualization
- Dashboard Reporting

## Dataset
The dataset contains information about food items, prices, restaurant details, ratings, and locations.

## Project Work
- Organized raw data and analysis into separate worksheets.
- Explored pricing and customer rating patterns.
- Compared food categories and geographical data.
- Created an Excel dashboard to present findings.

## Files Included
- `Swiggy Raw Data Excel.xlsx` — Excel workbook containing the data, analysis, and dashboard.

## Key Learnings
Practiced working with a large dataset, organizing information, analyzing patterns, and presenting results in Excel.
